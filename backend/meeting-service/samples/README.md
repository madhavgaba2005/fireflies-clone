# Sample transcripts

Upload these from the "New meeting" dialog (Upload tab) to try each supported format:

| File | Format |
|------|--------|
| `customer-onboarding.txt` | `[mm:ss] Speaker: text` |
| `standup.vtt` | WebVTT with `<v Speaker>` voice tags |
| `retro.json` | JSON list of `{speaker, start, end, text}` (seconds) |
