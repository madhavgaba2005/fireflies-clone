## 6. Submission checklist (author's actions)

1. **Publish the repository** (it stays private until you choose otherwise):
   ```bash
   gh repo create fireflies-clone --public --source . --remote origin   # or create it on github.com and:
   git remote add origin https://github.com/<you>/fireflies-clone.git
   git push -u origin main
   ```
   The local feature branches can be pushed too (`git push origin --all`) if you want them visible. Their PR
   descriptions are in [docs/PULL_REQUESTS.md](docs/PULL_REQUESTS.md).
2. **Watch the first GitHub Actions run** go green (four jobs).
3. **Choose a host** ([DEPLOYMENT.md](docs/DEPLOYMENT.md) §2; a free VM is recommended), then run:
   ```bash
   cp deploy/.env.example deploy/.env    # SITE_ADDRESS, PUBLIC_URL
   docker compose -f deploy/docker-compose.prod.yml --env-file deploy/.env up -d --build --wait
   ```
4. **Run the post-deploy checklist** (DEPLOYMENT §5) against the live URL.
5. **Put both links in the README** (Demo + GitHub sections) and submit them.
